name: status-update
description: Write a status update for the repository
---

Create a succinct status update of what has happened in the repository in the last week. It should be grouped by the user that has fixed the problem or worked in a particular PR. Do not focus on the details, give a high-level overview that could be shared in a couple of minutes in a meeting.

Send this update to the Slack `aiworkshopatjetbrains` workspace, in the private channel `serras-air` (channel id C0CB10YQK4L), as the "AIR" application using the given `SLACK_BOT_TOKEN` environment variable.

If sending through Slack fails and this is run through an automation, keep it as a result of such automation.
